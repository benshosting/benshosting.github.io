# Goose Walk Extension 🪿

A playful browser extension that brings “goose walking” to your browsing experience.  
Interact with the goose, tweak settings, and enjoy the fun.

## 🚀 Features
- Background script handles the goose logic  
- Popup UI to configure behaviors  
- Lightweight and easy to use  

## 🛠️ Usage
1. Install as an unpacked extension (in developer mode)  
2. Open popup to tweak settings  
3. Let the goose roam your tabs
